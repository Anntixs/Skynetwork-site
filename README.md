# SkyNetwork — сайт сети

Сайт сети виртуальной авиации SkyNetwork: регистрация и CID, карта и списки онлайна, планы полёта для SkyPilot, мероприятия, бронирование позиций, новости, обучение диспетчеров, поддержка, открытый API и закрытый раздел управления для команды. ASP.NET Core 8 (Razor Pages), SQLite.

## Разделы

**Для всех**
- **Главная**: кто в эфире, мини-карта, ближайшие мероприятия, новости, первые шаги.
- **Карта**: пилоты по курсу движения, диспетчеры с зонами. Обновляется каждые 15 секунд.
- **Онлайн**: диспетчеры в виде стрипов с частотами, пилоты с маршрутами.
- **Мероприятия**, **Новости**, **Бронирование позиций** (UTC).
- **Профиль участника**: рейтинг, часы пилотом и диспетчером, последние подключения.
- **Документация**: как начать, программы (SkyPilot, Network-ATC), рейтинги, правила, API.

**Для участника**
- **Регистрация**: выдаёт CID. Логин и пароль те же, что для подключения к сети.
- **Личный кабинет**: статистика, сессии, последний план.
- **План полёта**: подаётся на сайте, SkyPilot забирает его сам (см. ниже).
- **Обучение**: заявка на следующий рейтинг; инструктор отвечает и присваивает рейтинг.
- **Обращения** в поддержку, **настройки** (почта, страна, пароль).

**Управление** (`/staff`) — скрытый раздел. Для всех, кроме команды, его нет: ответ 404 без редиректа на вход, ссылок нигде не видно, `noindex`. Права зависят от рейтинга и ролей:

| Кто | Что может |
|---|---|
| ADM — администратор | всё, включая роли на сайте и любые рейтинги |
| SUP — супервайзер | участники, блокировки с причиной, заметки, онлайн, обращения, бронирования, мероприятия, новости, журнал |
| I1–I3 — инструкторы | заявки на обучение, рейтинги до C3, заметки, онлайн |
| роль «Мероприятия» / «Новости» | только свой раздел |
| роль «Поддержка» | обращения, поиск участников, сброс паролей |
| роль «Обучение» | как у инструктора |

Каждая страница управления проверяет своё право и без него отвечает 404. Каждое действие — рейтинг, блокировка, роли, сброс пароля, заметка, правка контента — пишется в **журнал действий**.

## Общая база с FSD-сервером

Сайт работает с той же SQLite-базой, что и `skynet-fsd` (параметр `--db`):
- таблица `members` — это таблица аккаунтов сервера, пароли хешируются так же (PBKDF2-SHA256, 200 000 итераций);
- участник, зарегистрированный на сайте, сразу подключается к сети;
- заблокированный на сайте не сможет подключиться;
- рейтинг, выставленный на сайте, действует в сети.

Остальные таблицы — собственные таблицы сайта.

Онлайн сайт берёт из `/data.json` сервера (HTTP-порт `skynet-fsd`) и по нему ведёт журнал подключений — отсюда часы и статистика.

## Запуск

```sh
# сервер сети
skynet-fsd --db /srv/skynetwork/skynetwork.db --port 6809 --http-port 8080
# первый администратор
skynet-admin --db /srv/skynetwork/skynetwork.db adduser 1000000 "Имя Фамилия" пароль ADM
# сайт
dotnet run --project src/SkyNetwork.Site -- --Site:Database=/srv/skynetwork/skynetwork.db
```

Настройки — в `appsettings.json`, раздел `Site`; любую можно передать аргументом `--Site:Имя=значение`:

| Настройка | По умолчанию | |
|---|---|---|
| `Database` | `skynetwork.db` | файл базы, общий с `skynet-fsd` |
| `DataFeedUrl` | `http://127.0.0.1:8080/data.json` | поток данных FSD-сервера; пусто — без онлайна |
| `FsdHost`, `FsdPort` | `127.0.0.1`, `6809` | адрес сервера на страницах «Как начать» |
| `FirstCid` | `1000001` | CID первого зарегистрированного |
| `BehindProxy` | `false` | за nginx: доверять `X-Forwarded-For/Proto` |
| `AuthAttemptsPerMinute` | `10` | попыток входа и регистрации в минуту с одного адреса |

Сайт слушает `http://0.0.0.0:8000` (`Urls` в `appsettings.json`), это адрес по умолчанию в SkyPilot. В продакшене поставьте перед ним nginx с HTTPS и включите `BehindProxy`.

## API

Открытый JSON API, только чтение, CORS разрешён. Описание — на странице `/developers`.

| Запрос | Что возвращает |
|---|---|
| `GET /api/v1/status` | название сети, адрес FSD, состояние данных |
| `GET /api/v1/online` | пилоты и диспетчеры в эфире |
| `GET /api/v1/stats` | участники, онлайн, подключения |
| `GET /api/v1/members/{cid}`, `…/sessions` | профиль и подключения участника |
| `GET /api/v1/events`, `/events/{id}`, `/bookings`, `/news` | мероприятия, бронирования, новости |
| `GET /api/flightplans/latest?cid=` | последний план участника для SkyPilot (формат — `docs/website-api.md` в репозитории SkyPilot) |

SkyPilot открывает `/flightplan?callsign=…` для подачи плана и забирает его из `/api/flightplans/latest`.

## Дизайн

Светлый и минималистичный: белый фон, один акцентный синий, шрифты Manrope, Inter и JetBrains Mono (лежат в `wwwroot/fonts`, лицензия OFL). Живой трафик оформлен как диспетчерские стрипы: цветная кромка по типу позиции, позывной моноширинным шрифтом. Leaflet тоже лежит локально (`wwwroot/lib/leaflet`); подложка карты — CARTO Light.

## Тесты

```sh
dotnet test
# с проверкой совместимости с настоящим сервером:
SKYNET_FSD_BUILD=/путь/к/Skynetwork-fsd/build dotnet test
```

Тесты:
- страницы и 404;
- регистрация, вход, блокировка;
- план полёта и API для SkyPilot;
- бронирования;
- скрытость раздела управления и права каждой страницы;
- повышение рейтинга инструктором;
- разбор потока данных и учёт сессий;
- аккаунты, общие с `skynet-fsd` и `skynet-admin`.
